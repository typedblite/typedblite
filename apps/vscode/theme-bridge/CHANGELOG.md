# Changelog

All notable changes to the TypeQLite Theme Bridge. It is versioned separately from the TypeDBLite extension and the
TypeDBLite npm packages. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

The first release. Nothing has been published to a marketplace yet.

### Added
- Reads your color theme's files where your local VS Code keeps them, so the TypeDBLite extension can color
  TypeQLite code blocks in the Markdown preview in your theme in a remote window (WSL, SSH, a container).
