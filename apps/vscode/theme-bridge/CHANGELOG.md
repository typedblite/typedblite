# Changelog

All notable changes to the TypeQLite Theme Bridge. It has the same version as the TypeDBLite extension, and is versioned
separately from the TypeDBLite npm packages. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [0.3.2] - 2026-11-26

No change to the Theme Bridge: its version follows the TypeDBLite extension's.

## [0.3.1] - 2026-11-26

The first published release. The version is the TypeDBLite extension's; earlier versions were never published.

### Added
- Reads your color theme's files where your local VS Code keeps them, so the TypeDBLite extension can color
  TypeQLite code blocks in the Markdown preview in your theme in a remote window (WSL, SSH, a container).
